# ChatApp

A Java-based chat application developed as part of my Software Development coursework.

## About the Project

This project is a practical Java application focused on implementing a simple messaging system between users.

The project helped me develop my understanding of Java programming, object-oriented programming, user input validation and working with stored data.

## Features

- User registration
- User login
- Password validation
- Sending and managing messages
- Message storage using JSON
- Message searching
- Message deletion
- Message reporting
- Input validation

## Technologies

- Java
- Maven
- NetBeans
- Gson
- JSON
- JUnit 5
- GitHub
